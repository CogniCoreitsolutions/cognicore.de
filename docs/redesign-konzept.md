# Redesign-Konzept — cognicore.de

Grundlage: **CogniCore Design System** (Navy-dominant, Orange nur Akzent, Raleway, „Sie", `//`-Motiv, Lucide) + **13-Agenten-Analyse** (adversarial verifiziert).

## Positionierung (der rote Faden)
Der stärkste, differenzierende Satz kommt aus dem Verborgenen nach vorn:
**„Kein klassisches Marketing — HubSpot-Partner mit Tiefgang in Datenmodell, Prozess- und API-Integration."**
Claim bleibt als visuelles Marken-Asset: *Damit es skaliert, nicht eskaliert.*
Framing des eigenen Decks: **HubSpot-first — „und mehr"** (IT-Projekte, Managed IT).

## Informationsarchitektur
- **Start** — Hero (POV + Proof-Zeile + 8-Wochen-Panel) · zwei Einstiegspfade (HubSpot schon/geplant) · Leistungen (6) · Vorgehen (5 Etappen) · Proof-Band (echte Belege) · Self-Check · Team-Teaser (mit Rollen) · Kontakt.
- **Leistungen** — HubSpot-Säule detailliert · „und mehr" (IT-Projekte, Managed IT/Satelliten) · Vorgehen · Preis-/Ablauf-Transparenz · FAQ (echte Phasen + Technik/Security) · CTA.
- **Über uns** — Team mit **echten Rollen** (GF Siegers/Lohmar vorn) · Mission · POV · 13 Zertifizierungen · „Passt zu euch?" · Karriere-Signal.
- **Kontakt** — Contact-Band mit echten Daten + Ansprechpartner Dominik Siegers + Platz für HubSpot-Meetings-Embed.
- **Recht** — Impressum · Datenschutz (an die *echte* Static-Technik angepasst) · Haftungsausschluss.

## Findings → Maßnahmen
| Finding (Schwere) | Maßnahme im Redesign |
|---|---|
| Kein Proof-Layer (hoch, 7/13) | Proof-Band mit **echten** Belegen: Solutions Partner, 13 Zertifizierungen, PLZ-Lookup-App („Proof of Build"), „eigener HubSpot-Betrieb". Struktur für Kunden-Cases vorbereitet. |
| Vorhandene Beweise versteckt (hoch) | Marketplace-App + Self-Check prominent als Conversion-Flächen. |
| Tiefe nur behauptet (hoch) | Konkrete Zielsysteme (ERP, DATEV, SAP, Make/n8n, APIs), Vorgehen mit Deliverables, technische FAQ. |
| Datenschutz ≠ Technik (hoch) | Neue DSE für den **Static-Auftritt ohne Tracking** (self-hosted Fonts, kein Analytics/Pixel); Kontaktdaten = Impressum. |
| Positionierung begraben (hoch) | POV in die Hero-Subline + Proof-Zeile; Title/H1 mit „HubSpot" + „Köln". |
| „Buchen" bucht nicht (hoch) | Ehrliches CTA-Label **„Erstgespräch vereinbaren"** (einheitlich); Kontakt-Sektion mit Formular + Telefon + Platz für Meetings-Embed. |
| Keine Preis-Orientierung (mittel) | Transparente Modell-Logik (Essential projektbasiert, Advanced/Excellence Retainer) — **ohne erfundene €-Zahlen**. |
| Generischer Ablauf/FAQ (mittel) | 5-Etappen-Vorgehen mit Deliverables; FAQ um Technik/Security/Datenhaltung erweitert. |
| Anrede uneinheitlich (mittel) | Durchgängig **„Sie"** (DS-Vorgabe). |
| Accessibility (Kontrast/Fokus) (mittel) | Sichtbarer `:focus-visible`, unterstrichene Links, Akzent-Orange abgedunkelt. |
| Performance Hero-Bild (mittel) | **Navy-Hero** (kein Foto) → LCP-Problem entfällt; übrige Bilder optimiert. |
| Lokal-SEO Köln (mittel) | „Köln" in Titles; JSON-LD Organization + LocalBusiness; sichtbarer NAP. |
| Karriere unsichtbar (Persona Bewerber) | Karriere-Signal auf Über-uns + Footer-Link. |

## Integritäts-Leitplanken (bewusste Entscheidungen)
- **Keine** erfundenen KPIs, Testimonials, Kundenlogos oder Preise. Nur belegbare Aussagen.
- Team: echte Rollen; nur bekannte Nachnamen (Siegers, Lohmar) ausgeschrieben.
- Partner-Tier korrekt: „Solutions Partner" (Basis), nicht Gold/Platin.
